# LEX Language

LEX is a simple and lightweight interpreted programming language. It currently provides the core fundamentals, including variables and the ability to print values to the console.

The project is still in active development. Planned features include process creation, process termination, file operations, and many other capabilities.

At the moment, LEX is only supported on Windows.
